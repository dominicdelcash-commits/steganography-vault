How the EOF method works
The carrier image bytes are kept intact. The application appends the secret payload after the original carrier bytes, then appends metadata, a 4-byte little-endian metadata length and the four-byte STEG EOF marker. Reveal starts from the end of the file, checks the marker, reads the metadata length, reads the metadata, and uses the recorded payload size to locate the hidden data. This version keeps that mechanism rather than replacing it with LSB.
